I've adapted the [Astro Milidev Astro Template](https://github.com/bartoszlenar/astro-milidev) to my own preferences:
1. Moved the light/dark/system theme selector from the footer to the header
2. Modified some minor logic that allows for light/dark bio profile display, the original does not adapt based on the theme.
3. Replaced or removed some generic/filler/templatey information with my own.
4. Added a new EndPostBio.astro Component in case you want something different to be shown in the end of each blog post instead of your entire bio.
5. Added some frontend fixes for the header elements to be centered and to work much better on smaller screens (Mobile)
